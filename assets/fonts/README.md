# خطوط المصحف

الخط المعتمد: **KFGQPC Uthmanic Script Hafs** من مجمع الملك فهد.

الترخيص (EULA): استخدام ونسخ وتوزيع مجاني **بشرط عدم التعديل أو البيع**.
لذلك لا يُعدَّل الخط ولا يُضمَّن أي ملف خط في المستودع قبل تأكيد الترخيص للنشر.

الإجراء عند الإضافة:
1. نزّل الملف الأصلي من `http://fonts.qurancomplex.gov.sa`.
2. ضعه هنا كما هو دون أي تعديل، مع نسخة من نص الترخيص `KFGQPC_EULA.txt`.
3. سجّله في `pubspec.yaml` تحت `fonts:` واستخدمه فقط لعرض الآيات.
4. وثّقه في `LICENSES_AND_SOURCES.md`.

حتى ذلك الحين يستخدم التطبيق خط النظام مع `Directionality.rtl` للآيات.
